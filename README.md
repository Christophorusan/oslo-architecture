# Oslo — Open Architecture for AI Agents on Hyperliquid

The public architecture writeup for **Oslo**, the AI agent system that runs Harmonix's protocol operations on Hyperliquid.

Implementation is private. The architecture is public — the same shape works for any protocol that wants AI agents handling BD, marketing, engineering, security, ops, and design without becoming a security or trust nightmare.

## What Oslo does

Turns Codex and Claude Code into a company operator that learns who matters, what is working, and what should happen next.

- **Signals** — what is happening on the surfaces Harmonix already operates
- **Audience Graph** — who is reacting, classified into users, partners, and lookalikes
- **Recommendations** — what to do next and why, posted for human approval
- **Units** — six departments (BD, Marketing, Engineering, Security, Ops, Design & UX) each with their own memory and playbooks
- **Connectors** — typed clients for X, Hyperliquid, DeFiLlama, Discord, Telegram, Notion
- **Safety** — capability tokens, symptom-triggered rules, Hyperliquid trade guard
